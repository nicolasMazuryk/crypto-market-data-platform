# Gap Analysis — code vs. `docs-strategy/strategies/**`

**Pass type:** analysis only, zero code changes. Verdicts are read-judgment against the spec with `path:line` citations; no engines/tests were run.

**Legend.** Verdict ∈ {**Conforms** (no task), **Partial** (some behavior right, gaps remain), **Missing** (absent), **Contradicts** (implements superseded/old behavior)}. Parity impact = whether the gap breaks backtest↔live parity (the central risk surface — the two engines share no code, only this spec). Task = the `NN` in `implementation-plan.md` / `tasks/`.

**Structural finding driving the whole plan.** Backtest (`src/backtesting/**`) and live (`src/execution/**`) are two independent implementations with no cross-imports and **no shared canonical schema** — directly contradicting globals §11.2.1 ("both schemas generated from one source of truth"). The live engine is broadly conformant; the backtest engine is missing multiple mandated conservatisms (latency, market slippage, correct `T_drop`, R7/R11 lifecycles) and is therefore **systematically optimistic**. Config validation is weak on both sides.
